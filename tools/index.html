复杂度速查

    

      
按数据范围反推可接受的复杂度（1 秒时限，C++）。

      

        
数据范围可接受复杂度典型算法

        
          
n ≤ 10O(n!)全排列、暴搜

          
n ≤ 20O(2n) / O(n·2n)状压 DP、子集枚举

          
n ≤ 100O(n3)Floyd、区间 DP

          
n ≤ 500O(n3) 常数小 / O(n2)矩阵乘、背包

          
n ≤ 5000O(n2)LCS、朴素 DP

          
n ≤ 2×105O(n log n)排序、线段树、堆

          
n ≤ 106O(n) / O(n log n)前缀和、双指针、筛法

          
n ≤ 107O(n) 常数极小线性筛、读入优化
